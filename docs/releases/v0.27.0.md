### Added
- `AgentDef.Role` for declarative fleet roles (jevons T511/T536.2).

### Changed
- Session MCP attach is `Config.MCPServers` only: Claude inline/temp `--mcp-config`, Grok/Cursor ACP `mcpServers`, Codex process-private temp `CODEX_HOME` when servers or `MCPExclusive` are set.
- `MCPExclusive` homes for Grok/Codex are system-temp (never workdir `.claudia-mcp-home`).
- Cursor exclusive Session MCP is ACP-only (no project `.cursor/mcp.json` rewrite).
- Registry Launch/Adopt no longer scans workdir `mcp.claudia.json` / `.mcp.json` and no longer writes Codex user config.

### Removed
- `EnsureMCP` / `EnsureMCPArgs`. Hosts that need durable user-scope MCP merges edit provider config themselves; Session never does.

### Docs
- agents-guide / README / STABILITY / Cursor ACP session notes updated for private Session MCP materialisation.
